herramientas que resuelvan un problema concreto: sitios web, programas de
escritorio y pequeños dispositivos que capturan datos.

llevar cada proyecto desde la idea hasta una versión que funcione.

## Proyectos destacados

### EKYVRA — registro de pulso

Dispositivo para llevar registro del pulso: detecta cada latido y calcula las
pulsaciones por minuto.

![Arduino](https://img.shields.io/badge/Arduino-00979D?logo=arduino&logoColor=white)
![C++](https://img.shields.io/badge/C%2B%2B-00599C?logo=c%2B%2B&logoColor=white)

- Detección de latidos con umbral adaptativo y filtros que reducen el ruido.
- Cálculo de pulsaciones por minuto (BPM).
- Gráfica del ritmo cardíaco en pantalla OLED.
- Semáforo de LEDs que indica el nivel del pulso.

📦 [Repositorio](https://github.com/Fajard05/ERYVRA) · 🟡 En desarrollo
