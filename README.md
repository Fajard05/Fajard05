## Sobre mí

Soy estudiante de Ingeniería en Computación en la ESPOL. Me interesa construir
herramientas que resuelvan un problema concreto: sitios web, programas de
escritorio y pequeños dispositivos que capturan datos.

Gran parte de mi tiempo lo dedico a fortalecer las bases de programación y a
llevar cada proyecto desde la idea hasta una versión que funcione.

## Áreas de interés

- Desarrollo de aplicaciones web y de escritorio.
- Bases de datos y consultas en SQL.
- Programación orientada a objetos con Java.
- Análisis de datos y automatización con Python.
- Dispositivos conectados y proyectos con Arduino (IoT).
